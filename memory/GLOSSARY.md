# Translation Memory — project glossary

Permanent terminology store for this localization project. Every new term that gets
translated MUST be recorded here so the next file translates consistently and fast.

Rules:

- One source term = one English term. Never re-invent an existing entry.
- Reuse an existing entry verbatim if the same concept appears again.
- If a source term is ambiguous in context, ask before adding a new entry.
- Keep this file sorted per section, append new sections at the bottom.
- Do not delete existing entries. Correct them in place only when clearly wrong.

- 普攻 is the classic MMO "normal attack" (the basic button, distinct from 技能 Skills).
  Rendered as `NormalAttack`, not `NormalAttack`, in all four entries.
- 轻功 is the xianxia/wuxia "lightness skill" (movement that defies gravity).
  Rendered as `LightSkill` to avoid the reading "light kung fu".
- 打坐 is meditation while seated. `Meditate`.

- 放暗器 means throwing a concealed projectile. `ThrowHiddenWeapon`.
- 悬停 means hovering in place. `Hover`.
- 空地 suffixes are weapon categories that the action name is appended to.
  空 means unarmed, rendered `None` rather than `Empty`.

## Known duplicate English names

These are correct, not a bug. Different source cities share the same English name,
and the parent province tells them apart.

| English | Source A | Source B |
| --- | --- | --- |
| Suzhou | 苏州市 (Jiangsu) | 宿州市 (Anhui) |
| Taizhou | 泰州市 (Jiangsu) | 台州市 (Zhejiang) |
| Yulin | 玉林市 (Guangxi) | 榆林市 (Shaanxi) |

Also expected: a province and its namesake capital city share the name
(北京 / 北京市 → Beijing, 吉林 / 吉林市 → Jilin, 重庆 / 重庆市 → Chongqing).
